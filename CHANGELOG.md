# Changelog

## 1.0.0 — first release for the Beyondex team

**Core**
- Workspaces, roles, invites and projects with custom workflows.
- Tasks with subtasks, checklists, dependencies, labels, custom fields and recurrence (including Jalali rules).
- Tasks can be proposed to teammates, who accept, decline or counter with a new date.
- Persian/English throughout with RTL, Jalali and Gregorian calendars, and Iranian holidays.

**Views and planning**
- Board, list, table, calendar, timeline/Gantt and workload views, with saved filters.
- Time tracking and timesheets.

**Methods**
- Sprints with burndown, OKRs, GTD, the Eisenhower matrix, focus/Pomodoro, habits and roadmap milestones.

**Automation and AI**
- Rule builder with a run log.
- OpenAI-powered quick-add, task breakdown, summaries, a workspace assistant, standups, and "plan my day".

**Collaboration**
- Notion-style docs with live co-editing (Yjs), slash commands, @mentions, live task chips, version history and meeting notes.
- Team chat with channels, DMs, threads and reactions; any message can become a task.

**Insights**
- Reports: CFD, cycle and lead time, throughput, per-person stats and aging WIP, plus CSV export.
- Gamification: XP, levels, streaks, 17 badges and a weekly Arena leaderboard.

**Mobile (Flutter)**
- Dashboard, tasks, board, calendar, chat, read-only docs, focus timer, AI assistant and Arena.
- Offline cache, biometric lock and system notifications.

**Integrations**
- Public REST API with API keys, and signed outgoing webhooks.
- GitHub commit/PR linking, a Telegram bot and a private iCal feed.
- CSV import from Jira, Trello, Asana and ClickUp.

**Operations**
- Docker images, a Caddy HTTPS stack with nightly backups, and a team seed script.
- Invite-only sign-up, a release workflow that publishes the images and an Android APK, and a deployment guide.
