# نصب Lumi روی VPS فعلی (بدون دامنه)

کل Lumi (وب، API و دیتابیس) روی همین سرور و پشت **یک پورت (8088)** بالا می‌آید:

**`http://95.38.191.245:8088`**

- به nginx، پورت‌های 80/443، فایروال و Frappe دست نمی‌زند.
- همه‌چیز در `/opt/lumi` و کانتینرهای `lumi-vps-*` قرار دارد.
- مصرف واقعی رم حدود ۱۶۰ مگابایت است. سقف هر بخش قفل شده تا به سیستم اصلی فشار نیاید.

## نصب: فقط همین
بعد از `ssh root@95.38.191.245` این یک خط را بزنید:
```bash
git clone https://github.com/pouya-wp/lumi.git /opt/lumi-src 2>/dev/null || git -C /opt/lumi-src pull; bash /opt/lumi-src/deploy/vps/install.sh
```
- فقط یک سؤال می‌پرسد: فهرست کانتینرهای hermes / opencode / warp را نشان می‌دهد و برای پاک کردنشان `y` بزنید.
- در آخر آدرس و رمز اولیه‌ی پویا، امیرحسین و متین را چاپ می‌کند. یک نسخه هم در `/opt/lumi/team-passwords.txt` ذخیره می‌شود.

## اپ‌ها
- **اندروید:** فایل APK را نصب کنید. آدرس سرور از قبل داخلش تنظیم شده است.
- **آیفون:** آدرس بالا را در Safari باز کنید، Share و بعد **Add to Home Screen**. با آیکون خودش و تمام‌صفحه باز می‌شود.

## نگهداری
| کار | دستور |
| --- | --- |
| آپدیت | همان دستور نصب را دوباره بزنید (داده‌ها و تنظیمات حفظ می‌شوند) |
| لاگ | `docker compose -p lumi-vps logs -f api` |
| مصرف رم | `docker stats --no-stream $(docker ps -q --filter name=lumi-vps)` |
| بکاپ | خودکار و روزانه در `/opt/lumi/backups` (۱۴ روز نگه داشته می‌شود) |
| توقف | `bash /opt/lumi-src/deploy/vps/uninstall.sh` (داده‌ها حفظ می‌شوند) |
| هوش مصنوعی (اختیاری) | `OPENAI_API_KEY` و `OPENAI_BASE_URL` (یک پروکسی، چون openai.com از ایران بسته است) را در `/opt/lumi/.env` بگذارید و دستور نصب را دوباره بزنید |

## نکته‌ها
- اتصال `http` است، یعنی رمزنگاری ندارد. برای استفاده‌ی داخلی تیم کافی است. هر وقت ساب‌دامنه گرفتید، HTTPS را بدون تغییر در بقیه‌ی سیستم اضافه می‌کنیم.
- اگر پورت 8088 روی سرور اشغال باشد، اسکریپت متوقف می‌شود و چیزی را عوض نمی‌کند. در آن صورت خبر بدهید تا پورت دیگری بگذاریم و APK را برای آن پورت دوباره بسازیم.
