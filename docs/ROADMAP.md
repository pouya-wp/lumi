# Lumi — Roadmap

| فاز | محتوا |
|---|---|
| **0** | اسناد (`docs/PRODUCT_SPEC.md`، `ARCHITECTURE.md`، `ROADMAP.md`) + اسکلت مونوریپو + docker-compose + CI |
